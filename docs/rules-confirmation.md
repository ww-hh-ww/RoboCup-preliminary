# 组委会规则确认清单

> 状态：⏳ 待发送
> 最后更新：2026-07-30

## 1. 输入方式

- [ ] 实时摄像头、视频文件还是单张照片？
- [ ] 摄像头是否由组委会提供？型号、分辨率、帧率？
- [ ] 程序运行几秒后取结果，还是持续实时识别？
- [ ] 人员和物品是否在同一画面同时出现？
- [ ] 比赛时是否允许联网？

## 2. 人脸规则

- [ ] 组委会每人提供几张头像？
- [ ] 照片是现场发放还是提前发放？
- [ ] 五人是否全部来自头像库？
- [ ] "干扰人"是否一定不在头像库中？
- [ ] 干扰人需要标记为 Unknown，还是不画框？
- [ ] 姓名和性别的具体显示格式？
- [ ] 侧脸、口罩、眼镜是否可能出现？

## 3. 物品规则

- [ ] "1～8 号物品清单"是八个类别还是八个具体实例？
- [ ] 是否提前提供实物或高清图片？
- [ ] 同类物品会不会同时出现多个？
- [ ] 方框颜色是否指定？
- [ ] 框旁显示物品编号还是名称？
- [ ] 评分看分类正确率、框位置，还是是否识别出来？
- [ ] 最大物品数量？遮挡比例大概多高？

## 4. 提交规则

- [ ] 操作系统限制？
- [ ] Python 及第三方库是否允许？
- [ ] 模型文件是否一并提交？
- [ ] 是否提交源代码？
- [ ] 是否有运行时间限制？
- [ ] 是否要求离线运行？
- [ ] 输入输出文件格式？
- [ ] 最终运行命令？
- [ ] 是否提供测试程序或样例数据？
